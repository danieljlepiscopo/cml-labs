# CML Labs
A list of comprehensive networking labs I've built in Cisco's Modeling Labs (CML).

## Goal
My goal for this repo is to build hands-on labs at the CCNP level. These labs will include concepts like:

- Dynamic Routing (OSPFv2, OSPFv3, and BGP)
- IP Services (HSRP and NAT)
- Security (ACLs)
- Network Automation (Ansible, Netmiko)

## Labs

| # | Lab | Topic | Skills |
|---|------|------|---------|
| 1 | Lab 1 | OSPF + BGP (Dual Stack) | Dynamic routing, IPv4/IPv6, and BGP peering |
| 2 | Lab 2 | HSRP + ACLs + NAT | Redundancy and Security |
| 3 | Lab 3 | Automation | Python, Netmiko, and Ansible |
